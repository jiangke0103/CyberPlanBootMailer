# CyberPlan Boot Mailer

一个不依赖 Codex 的 Windows 桌面应用，用于开机自动生成每日计划、弹窗提醒、发送邮件，并支持其他 AI 把计划导入每天的任务中。

## 一、主要功能

1. 电脑开机并登录 Windows 后，自动生成当天计划。
2. 同时生成 Markdown 和 Word 两种格式。
3. 自动弹出桌面通知，提醒今天先做什么。
4. 自动发送今日任务邮件，并附带 Word 文件。
5. 每天 21:00 发送复盘提醒邮件并弹出通知。
6. 周一只提示休息，不发送任务邮件。
7. 支持其他 AI 粘贴、导入或通过文件夹写入每日计划。
8. 邮箱授权码使用 Windows DPAPI 加密，只保存在当前电脑、当前用户下。
9. 完全不需要打开 Codex。

## 二、桌面应用入口

双击：

`启动桌面应用.lnk`

桌面应用包含四个页面：

- 今日计划：生成、刷新、预览、打开 Word、发送邮件。
- 外部 AI 计划：粘贴、导入、合并其他 AI 的任务安排。
- 自动运行与邮件：安装、修复、卸载开机自启，配置邮箱，查看日志。
- 使用教程：完整的应用内教程和故障排查。

## 三、第一次使用

1. 双击 `配置邮件.lnk`。
2. 选择邮箱类型。
3. 填写发件邮箱和 SMTP 授权码。
4. 程序会自动发送测试邮件。
5. 双击 `安装开机自启.lnk`。
6. 以后开机登录 Windows 后等待约 20 秒即可。

## 四、其他 AI 如何导入每天计划

### 方式一：桌面应用粘贴

1. 打开 `启动桌面应用.lnk`。
2. 切换到“外部 AI 计划”。
3. 把其他 AI 生成的 Markdown 或文本粘贴进去。
4. 点击“保存并合并”。
5. 应用会重新生成今日 Markdown 和 Word，并把内容加入“外部 AI 计划补充”。
6. 下次发送邮件时，邮件和 Word 附件会自动包含这部分内容。

### 方式二：文件夹自动接收

其他 AI 或脚本可以直接写入：

`imports\YYYY-MM-DD.md`

例如：

`imports\2026-09-15.md`

也支持 `.txt` 文件。开机生成今天的计划时，程序会自动读取并合并。

## 五、每天自动执行的时间线

| 时间 | 自动动作 |
|---|---|
| 开机并登录 Windows 后约 20 秒 | 生成计划、发送今日任务邮件、弹出桌面通知 |
| 周二至周日 21:00 | 发送复盘提醒邮件、弹出复盘通知 |
| 周一 | 只提示休息，不发送任务邮件 |

## 七、故障排查

### 没有生成计划

1. 打开桌面应用。
2. 进入“自动运行与邮件”。
3. 点击“安装/修复开机自启”。
4. 注销或重启 Windows 后再试。

### 没有收到邮件

1. 点击“立即发送今日邮件”。
2. 检查垃圾箱。
3. 如果仍然失败，点击“配置邮件”重新填写授权码。
4. 修改 QQ 密码后，旧授权码会失效，需要重新生成。

### Word 文件打不开或生成失败

先关闭已经打开的 Word 文件，再点击“生成/刷新今日计划”。

### 其他 AI 内容没有合并

确认以下两点：

1. 文件名严格为 `YYYY-MM-DD.md` 或 `YYYY-MM-DD.txt`。
2. 文件位于项目 `imports` 文件夹中。

## 八、安全说明

- 不要把 `config/email_secret.txt` 发给别人或上传到公开仓库。
- 邮箱授权码只用于本机自动发信。
- 项目不会扫描网络、不会攻击目标。
- 所有安全实验只能在自有虚拟机或明确授权靶场中进行。
