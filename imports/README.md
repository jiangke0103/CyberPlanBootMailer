# 其他 AI 计划导入说明

支持两种文件：

- `YYYY-MM-DD.md`
- `YYYY-MM-DD.txt`

例如今天日期是 2026-09-15，文件名应为：

`2026-09-15.md`

程序生成今日计划时，会自动读取该文件并追加到：
- 今日任务 Markdown
- 今日任务 Word
- 今日任务邮件

推荐内容格式：

```text
## 今日重点
- 完成虚拟机环境搭建
- 练习 Linux 常用命令

## 时间安排
09:20-11:20 虚拟机与网络基础
13:20-15:20 Linux 命令实验

## 注意事项
不要同时开多个方向。
```

也可以直接粘贴其他 AI 的普通文本或 Markdown，桌面应用会自动保存并合并。
